윈도우 업데이트가 몇 %에서 멈추거나 '설치 실패'가 반복되면 어디부터 손대야 할까요? 대부분은 재시작 → 저장공간 확보 → 업데이트 문제 해결사 순서로 해결돼요. 이 세 가지로 안 되면 업데이트를 잠시 멈췄다 다시 받거나, 시스템 파일을 검사하는 단계로 넘어가면 돼요.
11월 정기 보안 업데이트가 배포된 직후라 비슷한 문의가 늘어나는 시기예요. 쉬운 방법부터 순서대로 적었어요.


1단계: 가장 먼저 해볼 3가지

순서방법왜 효과가 있나
1다시 시작 (종료 말고 '다시 시작')대기 중인 설치 단계를 마무리
2저장공간 확보업데이트 파일 풀 공간 부족 해결
3문제 해결사 실행업데이트 구성 요소 자동 점검

윈도우 11에서는 설정 → 시스템 → 문제 해결 → 기타 문제 해결사 → Windows 업데이트 '실행' 순서로 들어가요.


2단계: 일시 중지 후 다시 받기

  1. 설정 → Windows 업데이트 → 업데이트 일시 중지 (1주 선택)
  2. PC 다시 시작
  3. 같은 화면에서 업데이트 다시 시작 → 업데이트 확인

받다 만 파일이 꼬였을 때 이 과정으로 새로 받는 경우가 많아요.

노트북은 충전기를 꽂은 상태에서 진행하세요. 배터리 절약 모드에서는 설치가 미뤄질 수 있어요.


3단계: 시스템 파일 검사

관리자 권한으로 터미널(명령 프롬프트)을 열고 아래 두 줄을 차례로 실행해요.

순서명령어하는 일
1DISM /Online /Cleanup-Image /RestoreHealth윈도우 이미지 복구
2sfc /scannow손상된 시스템 파일 복구

각각 몇 분에서 수십 분 걸릴 수 있어요. 끝나면 다시 시작한 뒤 업데이트를 확인해요.


오류 코드가 뜬다면?

'0x8'로 시작하는 오류 코드가 보이면 코드 전체를 그대로 검색하는 게 가장 빨라요. 마이크로소프트 지원에서 코드별 안내를 찾을 수 있어요.


업데이트 후에 문제가 생겼다면?

설정 → Windows 업데이트 → 업데이트 기록 → 업데이트 제거에서 최근 설치한 KB 번호를 골라 지울 수 있어요. 보안 업데이트는 다시 받는 게 원칙이라, 원인이 해결되면 재설치하세요.


저장공간은 어떻게 비우나요?

방법위치
임시 파일 삭제설정 → 시스템 → 저장소 → 임시 파일
저장소 센스 켜기설정 → 시스템 → 저장소
안 쓰는 앱 삭제설정 → 앱 → 설치된 앱

'임시 파일'에는 지난 업데이트 정리 파일이 들어 있는 경우가 많아요. 다운로드 폴더처럼 필요한 파일이 섞인 항목은 체크를 풀고 지우세요.

Q. 업데이트를 계속 미뤄도 되나요?
보안 업데이트는 해킹 위험을 막는 내용이 많아요. 오래 미루지 않는 게 좋아요.

Q. 회사 PC도 이렇게 해도 되나요?
회사 IT 정책이 우선이에요. 담당 부서에 먼저 문의하세요.


순서대로 체크

  • ☐ 종료가 아니라 '다시 시작'을 했는지
  • ☐ C 드라이브 여유 공간이 충분한지
  • ☐ Windows 업데이트 문제 해결사를 실행했는지
  • ☐ 일시 중지 후 다시 받기를 해봤는지
  • ☐ DISM과 sfc 검사를 했는지
