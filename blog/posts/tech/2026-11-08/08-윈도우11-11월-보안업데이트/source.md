마이크로소프트의 **11월 정기 보안 업데이트**가 미국 시간 11월 10일, **한국 시간 11월 11일**에 배포될 예정이에요. 매달 둘째 주 화요일(미국 기준)에 나오는 '패치 화요일' 업데이트입니다.

## 11월 업데이트 일정

| 항목 | 내용 |
|---|---|
| 배포일 | 미국 11월 10일 → **한국 11월 11일** |
| 대상 | 윈도우 11 26H2·25H2 (보도 기준) |
| KB 번호 | KB5127936 (해외 보도 기준) |

KB 번호와 세부 수정 내용은 **배포 직후 MS 공식 문서**에서 확인하는 게 정확해요. MS 한국어 릴리스 페이지에는 아직 상세 정보가 비어 있었어요.

## 업데이트 전 체크

| 체크 | 이유 |
|---|---|
| 중요한 작업 저장 | 재부팅 필요 |
| 저장 공간 | 업데이트 파일 공간 확보 |
| 노트북 전원 | 충전기 연결 |
| 업무용 PC | 회사 IT 정책 확인 |

## 업데이트하는 법

1. **설정 → Windows 업데이트**
2. **업데이트 확인** 누르기
3. 다운로드·설치 후 **다시 시작**

## 업데이트 후 문제가 생기면

- 설정 → Windows 업데이트 → **업데이트 기록**에서 설치된 KB 확인
- 문제가 계속되면 **업데이트 제거** 가능
- 같은 증상이 많으면 MS가 알려진 문제로 공지하는 경우가 있어요

## 윈도우 업데이트 종류 정리

| 종류 | 시기 | 내용 |
|---|---|---|
| 정기 보안 (B) | 매월 둘째 화요일 | 보안 수정 + 일부 기능 |
| 선택 미리보기 (D) | 매월 넷째 주 | 다음 달 기능 미리 |
| 기능 업데이트 | 연 1회 | 26H2 같은 큰 버전 |

**선택 업데이트**는 굳이 바로 안 받아도 되지만, **정기 보안 업데이트**는 받는 게 좋아요.

## 업데이트 시간 정하기

**설정 → Windows 업데이트 → 고급 옵션 → 사용 시간**을 지정하면 그 시간에는 자동 재부팅이 되지 않아요. 수업·업무 중 갑자기 재부팅되는 걸 막을 수 있어요.

## 자주 나오는 질문

**Q. 윈도우 10도 받나요?**
일반 지원이 끝나 ESU(확장 보안 업데이트) 가입 기기만 받아요.

**Q. 꼭 바로 설치해야 하나요?**
보안 업데이트라 가능하면 빨리 설치하는 걸 권장해요.
