아이폰에 '저장 공간 거의 가득 참' 알림이 뜬다면 **설정 → 일반 → iPhone 저장 공간**부터 열어보세요. 이 화면에서 어떤 앱과 데이터가 공간을 많이 쓰는지 한눈에 보이고, 아이폰이 추천하는 정리 방법도 함께 나와요. 사진은 클라우드로, 안 쓰는 앱은 '앱 정리하기'로 처리하면 데이터를 잃지 않고 공간을 되찾을 수 있어요.

## 무엇이 공간을 많이 쓰나요?

| 흔한 원인 | 정리 방법 |
|---|---|
| 사진·동영상 | iCloud 사진 + 'iPhone 저장 공간 최적화' |
| 메시지 첨부 파일 | 메시지 보관 기간 설정, 큰 첨부 파일 삭제 |
| 안 쓰는 앱 | 앱 정리하기 (데이터는 남기고 앱만 삭제) |
| 스트리밍 앱 오프라인 저장 | 다 본 영상 삭제 |
| 시스템 데이터 | 재시동 후 변화 확인 |

## '앱 정리하기'와 '앱 삭제'의 차이

| 구분 | 앱 정리하기 | 앱 삭제 |
|---|---|---|
| 앱 본체 | 삭제 | 삭제 |
| 문서·데이터 | **남겨둠** | 함께 삭제 |
| 다시 설치하면 | 이전 데이터 그대로 | 처음부터 |

잘 안 쓰지만 기록은 남기고 싶은 앱이라면 '앱 정리하기'가 안전해요. **설정 → 앱 → App Store → 사용하지 않는 앱 정리하기**를 켜두면 오래 안 쓴 앱을 자동으로 정리해 줘요. 메뉴 위치는 iOS 버전에 따라 조금 다를 수 있어요.

> 저장 공간 관리 방법은 [애플 지원](https://support.apple.com/ko-kr)에서도 확인할 수 있어요.

## 사진을 정리할 때 주의할 점

'iPhone 저장 공간 최적화'를 켜면 원본은 iCloud에 두고 기기에는 작은 버전만 남겨 공간을 아껴요. 다만 iCloud 용량이 부족하면 백업이 멈출 수 있어서, iCloud 저장 공간도 함께 확인해야 해요. 사진을 지울 때는 '최근 삭제된 항목'에서도 지워야 공간이 바로 늘어나요.

| 사진 정리 순서 | 할 일 |
|---|---|
| 1 | iCloud 용량 확인 |
| 2 | iCloud 사진 켜고 업로드 완료 확인 |
| 3 | 저장 공간 최적화 켜기 |
| 4 | 최근 삭제된 항목 비우기 |

## 메시지 보관 기간 바꾸기

**설정 → 메시지 → 메시지 보관**에서 기간을 '30일'이나 '1년'으로 바꾸면 오래된 메시지와 첨부 파일이 자동으로 정리돼요. 중요한 대화가 있다면 바꾸기 전에 캡처나 백업을 해두세요.

## 정리 후에도 금방 차는 이유

메신저 앱의 자동 다운로드, 동영상 앱의 오프라인 저장, 사진 연속 촬영(버스트)이 대표적인 원인이에요. 한 번 정리한 뒤에는 이런 자동 저장 설정을 함께 꺼두면 공간이 다시 빠르게 차는 걸 막을 수 있어요. 한 달에 한 번 저장 공간 화면을 열어보는 습관도 도움이 돼요.
