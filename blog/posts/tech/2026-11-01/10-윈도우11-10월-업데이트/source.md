윈도우 11 사용자라면 **10월 보안 업데이트**를 설치했는지 확인해 보세요. 마이크로소프트는 10월 13일(미국 시간) 정기 보안 업데이트를 배포했고, 그중에는 **이미 실제 공격에 악용된 취약점(제로데이)**도 포함됐어요.

다음 정기 업데이트는 **11월 10일(미국 시간)**입니다. 10월 업데이트에서 바뀐 점과 확인 방법을 정리했어요.

## 10월 업데이트 한눈에

| 항목 | 내용 |
|---|---|
| 배포일 | 10월 13일 (미국 시간) |
| 누적 업데이트 | 24H2·25H2·26H2: **KB5127648** / 26H1: KB5127646 |
| 핵심 보안 수정 | Windows Shell 명령 주입 취약점 (CVE-2026-96951, **실제 악용**) |
| 다음 정기 업데이트 | **11월 10일** (미국 시간) |

※ 마이크로소프트 공식 블로그·지원 문서와 보안 매체 보도 기준

## 왜 꼭 설치해야 하나

이번에 고친 취약점 중 하나는 공격자들이 이미 **인터넷에서 받은 파일을 경고 없이 실행되게 만드는 데** 악용한 것으로 보도됐어요. 업데이트를 미루면 이런 공격에 노출될 수 있습니다.

## 함께 고쳐진 불편함

| 분류 | 내용 |
|---|---|
| 버그 수정 | 블루투스 안정성, 일부 게임 마우스 끊김, 지문 로그인, 인쇄, VPN 연결 |
| 26H1 문서 | 로그인 후 검은 화면 문제 관련 수정 |
| 새 기능 | 앱 항상 최대화 실행 옵션, Copilot 키 재지정, 'Tips' 위젯, 터치패드 제어 |

## 업데이트 확인 방법

1. **설정 → Windows 업데이트**
2. '업데이트 확인' 클릭
3. 설치 후 **재시작**
4. '업데이트 기록'에서 KB5127648(또는 내 버전 번호) 확인

## 업데이트 전 체크리스트

- 중요한 파일 **백업**
- 노트북은 **전원 연결**
- 회사 PC는 IT 부서 정책 확인
- 업데이트 후 문제가 생기면 '업데이트 기록 → 업데이트 제거' 메뉴 확인

## 윈도우 10은요?

윈도우 10은 일반 지원이 끝나 ESU(연장 보안 업데이트) 가입 여부에 따라 보안 업데이트를 받는 구조예요. 윈도우 10 사용자라면 예전에 정리한 ESU 글을 참고하세요.

## 자주 나오는 질문

**Q. 업데이트하면 느려지나요?**
대부분 체감 차이는 크지 않아요. 문제가 생기면 업데이트 기록에서 해당 업데이트를 확인하세요.

**Q. 11월 10일엔 또 해야 하나요?**
네, 매달 정기 보안 업데이트가 나오니 그때도 설치하세요.
