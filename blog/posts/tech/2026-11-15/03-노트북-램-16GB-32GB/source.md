노트북을 살 때 램은 16GB면 될까요, 32GB가 필요할까요? 문서 작업·강의 시청·웹 검색 위주라면 **16GB로도 대부분 충분**하고, 영상 편집·개발 도구·최신 게임을 함께 쓴다면 **32GB가 여유로워요**. 요즘 노트북은 램이 메인보드에 붙어 나오는 경우가 많아서, 나중에 늘리기 어렵다는 점까지 생각하고 골라야 해요.

## 용도별로 보면 어떻게 고를까요?

| 주 용도 | 권장 램 (일반적 기준) | 이유 |
|---|---|---|
| 문서·과제·온라인 강의 | 16GB | 브라우저 탭을 많이 열어도 여유 |
| 디자인·사진 편집 | 16~32GB | 고해상도 파일은 메모리를 많이 씀 |
| 영상 편집·3D·개발 | **32GB** | 여러 프로그램 동시 실행 |
| 최신 게임 | 16GB 이상, 여유 있으면 32GB | 게임 권장 사양 확인 |

윈도우 11 자체의 최소 요구 사양은 4GB지만, 실제로 쾌적하게 쓰려면 훨씬 넉넉해야 해요. 최소 사양은 [마이크로소프트 윈도우 11 사양 안내](https://www.microsoft.com/ko-kr/windows/windows-11-specifications)에서 확인할 수 있어요.

## 나중에 늘릴 수 있는지 먼저 보세요

| 램 구조 | 업그레이드 | 사기 전 판단 |
|---|---|---|
| 온보드(메인보드에 고정) | **불가** | 처음부터 넉넉하게 |
| 온보드 + 슬롯 1개 | 슬롯만큼 추가 가능 | 슬롯 규격 확인 |
| 슬롯 2개 | 교체·추가 가능 | 저렴한 모델 후 증설도 가능 |

얇고 가벼운 노트북일수록 온보드 구조가 많아요. 상품 상세의 '메모리 슬롯' 항목이 비어 있다면 제조사 사양표에서 한 번 더 확인하세요.

## 가격 차이는 어떻게 판단할까요?

램 가격이 오르면서 16GB와 32GB 모델의 가격 차이도 커졌어요. 이럴 땐 **앞으로 몇 년 쓸지**를 기준으로 보면 판단이 쉬워요. 4년 이상 쓸 계획이고 업그레이드가 안 되는 모델이라면, 처음에 조금 더 내고 32GB를 고르는 쪽이 길게 보면 덜 아쉬워요.

| 비교 기준 | 16GB 모델 | 32GB 모델 |
|---|---|---|
| 초기 가격 | 낮음 | 높음 |
| 3~4년 뒤 체감 | 무거운 작업에서 부족할 수 있음 | 여유 있음 |
| 업그레이드 불가 모델 | 그대로 써야 함 | 걱정 적음 |

## 램 말고도 같이 볼 것

- **SSD 용량**: 512GB 이상이면 과제·사진 보관에 여유
- **CPU 세대**: 같은 램이라도 CPU가 오래되면 체감이 떨어짐
- **무게·배터리**: 매일 들고 다닌다면 1.5kg 이하가 편함
