GTA6가 11월 19일 PS5와 Xbox Series X|S로 출시된 날, 플레이스테이션 네트워크(PSN) 로그인 실패와 서버 연결 오류를 겪었다는 신고가 이어졌다는 보도가 나왔어요. 지금 접속이 안 된다면 내 기기 문제인지 서버 문제인지부터 가리는 게 먼저예요. **PSN 서비스 상태 페이지 확인 → 시스템 업데이트 → 네트워크 재연결** 순서로 보면 대부분 원인을 좁힐 수 있어요.

## 내 문제일까, 서버 문제일까?

| 확인할 것 | 서버 문제일 가능성 | 내 기기 문제일 가능성 |
|---|---|---|
| PSN 상태 페이지 | 장애 표시가 있음 | 정상으로 표시 |
| 다른 온라인 게임 | 다른 게임도 접속 안 됨 | 다른 게임은 잘 됨 |
| 친구·커뮤니티 반응 | 같은 시간대 오류 신고 많음 | 나만 안 됨 |

서버 장애라면 집에서 아무리 설정을 바꿔도 해결되지 않아요. 이때는 상태 페이지에서 복구 소식을 기다리는 게 가장 빠른 방법이에요. 서비스 상태는 [PlayStation Network 서비스 상태](https://status.playstation.com/)에서 볼 수 있어요.

## 시스템 소프트웨어 업데이트부터 확인하세요

출시 직전 배포된 PS5 시스템 업데이트를 설치해야 게임이 정상 실행된다는 안내가 보도된 바 있어요. **설정 → 시스템 → 시스템 소프트웨어 → 시스템 소프트웨어 업데이트**에서 최신 버전인지 확인하고, 게임 자체 패치도 받아졌는지 게임 아이콘의 옵션 메뉴에서 '업데이트 확인'을 눌러 보세요.

| 순서 | 할 일 |
|---|---|
| 1 | 시스템 소프트웨어 최신 버전 확인 |
| 2 | 게임 업데이트 확인 |
| 3 | PS5 완전히 끄고 다시 켜기 (휴식 모드 아님) |
| 4 | 공유기 전원 껐다 켜기 |
| 5 | 가능하면 랜선으로 유선 연결 |

> 게임을 지우고 다시 설치하는 방법은 용량이 커서 시간이 매우 오래 걸려요. 서버 문제라면 재설치해도 해결되지 않으니 가장 마지막에 생각하세요.

## 스토리 모드는 할 수 있을까요?

온라인 서버가 불안정할 때도 혼자 하는 스토리 진행은 상대적으로 영향을 덜 받는 경우가 많아요. 다만 게임 실행 시 계정 확인을 위해 PSN 연결이 필요할 수 있어서, 완전히 오프라인으로 즐길 수 있는지는 상황에 따라 달라요. 접속이 안 되는 시간에는 무리하게 재시도를 반복하기보다 잠시 쉬었다가 다시 시도하는 편이 나아요.

## 오류 코드가 뜬다면

화면에 오류 코드가 표시되면 그 코드를 그대로 메모해 두세요. 플레이스테이션 고객지원에서 오류 코드로 원인과 해결 방법을 안내하는 경우가 많아요. 코드를 검색할 때는 공식 지원 페이지를 먼저 확인하는 게 안전해요.

## 친구와 같이 하려면 확인할 것

친구와 온라인으로 함께 하려면 서로의 PS Plus 구독 상태와 게임 버전이 같은지 확인하세요. 한쪽만 패치가 덜 되어 있으면 같은 세션에 들어가지 못할 수 있어요.

**Q. 계정 정지 같은 문제일 수도 있나요?**
출시 직후처럼 많은 사람이 동시에 겪는 오류라면 서버 혼잡 가능성이 훨씬 커요. 계정 관련 안내는 이메일이나 공식 알림으로 오니 함께 확인하세요.

**Q. 엑스박스도 같은 방법인가요?**
엑스박스는 Xbox 서비스 상태 페이지를 확인하고, 콘솔 재시작과 네트워크 점검 순서는 비슷해요.

오늘 접속이 안 된다면, 상태 페이지 확인과 시스템 업데이트 두 가지부터 해보세요.
