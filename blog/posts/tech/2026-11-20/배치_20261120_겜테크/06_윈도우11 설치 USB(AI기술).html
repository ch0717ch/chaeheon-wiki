윈도우 11 설치 USB, 어떻게 만들까요? 마이크로소프트가 무료로 제공하는 미디어 생성 도구 하나면 돼요. 8GB 이상 USB를 꽂고 도구를 실행한 뒤 'USB 플래시 드라이브'를 고르면 설치 파일이 자동으로 담겨요. 새 PC 조립, 윈도우 10에서 깨끗하게 새로 설치, 고장 난 윈도우 복구까지 한 개의 USB로 해결할 수 있어서 하나쯤 만들어 두면 편해요.


준비물은 무엇인가요?

준비물기준
USB 메모리8GB 이상 (안의 파일은 모두 지워짐)
인터넷이 되는 윈도우 PC도구 다운로드·설치 파일 내려받기
윈도우 정품 인증기존 PC는 대부분 자동 인증, 새 PC는 제품 키 필요
설치할 PC 사양TPM 2.0, 지원 CPU 등 윈도우 11 요구 사항

USB에 있던 파일은 전부 지워지니, 필요한 자료는 미리 다른 곳에 옮겨두세요.


만드는 순서

  1. 마이크로소프트 윈도우 11 다운로드 페이지에서 설치 미디어 만들기 도구 받기
  2. 도구 실행 후 사용 조건 동의
  3. 언어·에디션 선택 (보통 '이 PC에 권장 옵션 사용')
  4. USB 플래시 드라이브 선택 후 꽂아둔 USB 고르기
  5. 다운로드와 USB 작성이 끝날 때까지 기다리기

인터넷 속도에 따라 시간이 꽤 걸릴 수 있어요. 진행 중에는 USB를 빼거나 PC를 끄지 마세요.

이미 윈도우 10을 쓰는 PC를 업그레이드만 할 거라면 USB 없이 '설치 도우미'로 바로 업그레이드하는 방법도 있어요.


USB로 설치를 시작하는 방법

설치할 PC에 USB를 꽂고 전원을 켠 뒤 부팅 메뉴 키를 누르면 USB를 선택할 수 있어요. 부팅 메뉴 키는 제조사마다 달라서 F12, F11, ESC 등을 쓰는 경우가 많아요.

상황해결
USB가 부팅 목록에 안 보임USB를 다른 포트에 꽂기, 바이오스에서 USB 부팅 확인
'TPM 미지원' 안내바이오스에서 TPM(PTT·fTPM) 켜기
설치할 드라이브 안 보임저장장치 드라이버 확인


새로 설치 전에 백업할 것

  • 바탕화면·문서·사진 폴더
  • 브라우저 즐겨찾기와 저장된 비밀번호
  • 공동인증서 등 인증서 파일
  • 사용 중인 프로그램의 라이선스 키

깨끗하게 새로 설치하면 C 드라이브가 초기화될 수 있어서, 백업을 먼저 끝낸 뒤 설치를 시작하는 게 안전해요.


설치가 끝난 뒤 할 일

설치가 끝나면 설정 → Windows 업데이트에서 업데이트를 모두 받고, 장치 관리자에서 느낌표가 뜬 드라이버가 없는지 확인하세요. 그래픽카드 드라이버는 제조사 홈페이지에서 최신 버전을 받는 게 좋아요. 정품 인증 상태는 설정의 정품 인증 메뉴에서 확인할 수 있어요. 백업해 둔 파일은 업데이트까지 끝낸 다음에 옮겨야 중간에 다시 설치할 일이 생겨도 안전해요.


USB는 어떤 걸 고르면 될까요?

USB 3.0 이상 제품을 쓰면 만드는 시간과 설치 시간이 줄어들어요. 오래된 USB는 쓰기 오류가 날 수 있으니 가능하면 상태가 좋은 제품을 쓰세요.

Q. 맥에서도 만들 수 있나요?
미디어 생성 도구는 윈도우용이에요. 맥에서는 ISO 파일을 받아 별도 방법으로 만들어야 해요.

Q. USB를 다시 일반 용도로 쓸 수 있나요?
설치가 끝난 뒤 포맷하면 다시 쓸 수 있어요.

백업만 끝났다면 USB 만들기는 어렵지 않아요.
