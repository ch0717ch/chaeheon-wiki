오픈AI가 11월 17일(미국 시간) **GPT-6.2 아스트라(Astra)**와 **GPT-6.2 솔(Sol)**을 함께 공개했어요. 아스트라는 금융 모델 구축·과학 연구 같은 **복잡한 전문 업무용**, 솔은 **일상 작업용**으로 소개됐어요. 앞서 9월에 공개하려던 6.1 버전이 안전 문제로 출시가 보류됐다는 보도가 있었던 만큼, 두 달 만의 신모델이라 관심이 커요.

## 아스트라와 솔, 무엇이 다른가요?

| 구분 | GPT-6.2 아스트라 | GPT-6.2 솔 |
|---|---|---|
| 용도 | 복잡한 전문 업무 | 일상 작업 |
| API 입력 (100만 토큰) | 8달러 | 2달러 |
| API 출력 (100만 토큰) | 40달러 | 10달러 |
| 가격 비교 | — | 같은 사용량 기준 약 4분의 1 |

API 가격은 보도 기준이에요. 솔은 기존 버전과 같은 가격을 유지했다는 보도도 있어요.

## 내 요금제에서 쓸 수 있나요?

| 요금제 | 이용 범위 (보도 기준) |
|---|---|
| 무료 | 제공되지 않음 |
| 플러스·프로·엔터프라이즈·에듀 | 챗GPT Work와 Codex에서 사용 |
| 일반 챗GPT 대화 | 아직 모델 선택에 추가되지 않았다는 보도 |

일반 대화창이 아니라 업무용 환경(Work)과 코딩 도구(Codex) 위주로 먼저 열렸다는 점이 이번 출시의 특징이에요. 무료 계정으로는 쓸 수 없다고 알려져 있어요.

## 일반 사용자가 볼 포인트

일상적인 질문이나 글쓰기라면 당장 큰 차이를 느끼기 어려울 수 있어요. 업무용 Work 환경이나 Codex를 쓰는 유료 구독자라면 모델 선택 메뉴에서 새 모델이 보이는지 확인해 보세요. API로 쓰는 개발자는 아스트라와 솔의 가격 차이가 4배라, 작업 난이도에 따라 나눠 쓰는 게 비용을 아끼는 방법이에요.

## 기업·학교 사용자는 어떻게 되나요?

엔터프라이즈·에듀 요금제도 사용 대상에 포함된다고 보도됐어요. 회사나 학교 계정이라면 관리자가 새 모델 사용을 허용했는지에 따라 보이는 메뉴가 다를 수 있어요. 업무에 바로 쓰기 전에 사내 보안 정책과 데이터 처리 기준도 함께 확인하세요.

| 계정 종류 | 확인할 것 |
|---|---|
| 개인 유료 | Work·Codex 메뉴에 새 모델 표시 여부 |
| 회사·학교 | 관리자 허용 여부, 보안 정책 |
| 개발자 | API 가격과 사용량 한도 |
