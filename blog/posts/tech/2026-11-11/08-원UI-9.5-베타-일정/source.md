갤럭시 S26을 쓰는 분들이 궁금해하는 **One UI 9.5 베타**가 이르면 **11월 중순~하순** 시작될 수 있다는 전망이 나와요. 삼성 서버에서 S26 울트라용 베타 빌드가 발견됐기 때문인데, **삼성 공식 발표는 아직 없어요.**

## 지금까지 나온 이야기

| 항목 | 내용 |
|---|---|
| One UI 9 정식 | S26 시리즈 **9월 16일**(한국)부터 배포 |
| 9.5 베타 시작 전망 | 11월 16~24일 (23일 유력, 일부 보도) / 11월 말~12월 초 (다른 보도) |
| 근거 | S26 울트라용 베타 빌드 발견 |
| 9.5 정식 | 2027년 초 **갤럭시 S27과 함께** 전망 |
| 공식 발표 | **없음** |

지난해 One UI 8.5 첫 베타는 11월 25일이었는데, 이번엔 그보다 빨라질 수 있다는 분석이에요.

## 베타 참여 방법 (예년 기준)

1. **삼성 멤버스** 앱 실행
2. 베타 프로그램 배너 또는 공지 확인
3. 신청 후 **소프트웨어 업데이트**에서 다운로드

S26 울트라가 먼저 시작되고 **S26·S26+는 뒤따를 가능성**이 커요.

## 베타 참여 전 체크

| 체크 | 이유 |
|---|---|
| 백업 | 오류 시 데이터 손실 대비 |
| 금융 앱 | 일부 앱이 베타에서 오류 가능 |
| 배터리 | 초기 베타는 배터리 소모 늘 수 있음 |
| 되돌리기 | 정식으로 돌아가려면 초기화가 필요할 수 있음 |

**업무·결제용 메인 폰**이라면 정식 버전을 기다리는 게 안전해요.
