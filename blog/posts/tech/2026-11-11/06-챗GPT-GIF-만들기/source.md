챗GPT에서 이제 **움직이는 GIF**를 만들 수 있어요. 오픈AI가 11월 4일 **ChatGPT Images 2.6**을 내놓으면서 GIF 생성과 **참조 이미지 저장** 기능이 추가됐어요. 기능이 **순차 적용 중**이라 아직 안 보이는 분도 있을 수 있어요.

## 새로 생긴 기능

| 기능 | 설명 |
|---|---|
| GIF 생성 | 글이나 이미지로 **반복 재생 GIF** 만들기 |
| 속도 조절 | 재생 속도 바꾸기 |
| 참조 이미지 저장 | 한 번 저장한 사진을 다른 대화에서 **다시 올리지 않고** 사용 |

## 이렇게 써볼 수 있어요

| 하고 싶은 것 | 요청 예시 |
|---|---|
| 손 흔드는 캐릭터 | "이 캐릭터가 손을 흔드는 반복 GIF 만들어줘" |
| 블로그용 움짤 | "커피에서 김이 올라오는 GIF" |
| 반려동물 | 저장한 반려견 사진으로 "꼬리 흔드는 GIF" |

## 쓰기 전 알아둘 것

| 체크 | 이유 |
|---|---|
| 적용 시기 | 계정마다 **순차 적용** |
| 이용 한도 | 무료·유료 요금제별 차이 가능 |
| 저작권 | 남의 캐릭터·사진 사용 주의 |
| 사람 얼굴 | 실존 인물 이미지 생성 제한 있을 수 있음 |

## 개발자용 새 모델도

API에서는 빠른 생성용 **GPT-Image-2.6 Flare**(약 6초 생성)와 품질 중심 **Sunburst**(SVG 내보내기 등)가 함께 나왔어요.
