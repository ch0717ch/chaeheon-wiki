## 2. 레퍼런스에서 가져올 것 (정보형 고유입 블로그 공통 패턴)

**이미지 스타일** (사용자가 보내준 쓰리휴먼스 썸네일 캡처 기준 — 이 형식을 모든 글에 적용)
- 실물 소품이 놓인 밝은 책상 장면 배경 (교재·폰·서류 등 주제 물건이 오른쪽에 크게)
- 좌상단 기울어진 **빨간 붓터치 배너** + 노란 강조선: "이번 수특 표지?!" 처럼 짧은 질문/감탄
- **검은 두꺼운 외곽선 + 그림자의 초대형 제목 3줄**, 줄마다 흰 → 노랑 → 하늘 그라데이션, 살짝 기울임
- 노란 포스트잇에 **손글씨 체크리스트 4줄** = 글 목차
- 하단 **4칸 미리보기 타일**: 작은 그림 + 검정 1줄 / 빨강 1줄 캡션 ("출간 일정 / 언제?")
- 한 화면에 정보가 꽉 차 보이게 → "들어가면 이게 다 정리돼 있다"는 인상을 줌

**글 스타일**
- 도입 2~3문장 안에 독자의 상황을 짚고 답의 방향을 먼저 말함
- 소제목은 질문형/결론형 ("그래서 금액은 줄어드나요?")
- 표 1~2개, 체크리스트, FAQ 2~3개, 마지막 "정리하면" 박스
- 기준일과 출처를 글 끝에 명시 → 신뢰 + 업데이트 글로 재활용

**검색 유도 스타일**
- 제목 앞쪽 15자 안에 메인 키워드
- 연도·숫자·질문 하나를 섞되 과장 표현은 쓰지 않음
- 태그 10개: 메인 2 + 롱테일 5 + 카테고리 3 (`#대학생활정보`는 매 글 고정)

## 3. 하지 않을 것 (이 블로그를 지키기 위한 선)

- 레퍼런스 블로그의 문장·이미지 그대로 복제 — 형식만 참고하고 내용은 직접 조사
- 확인 안 된 마감일·금액·후기 작성 (애드포스트 품질 평가에서 가장 위험)
- "광고 눌러주세요" 류 문구
- 같은 키워드로 표현만 바꾼 글 반복

## 5. 하루 3개 구성 원칙

1. **시즌/뉴스 1개** — 지금 발표되거나 곧 마감되는 것
2. **비교·판단 1개** — "A vs B", "언제 지원해야", "어떤 걸 골라야"
3. **방법·해결 1개** — 발급, 신청, 오류 해결처럼 매년 검색되는 에버그린

세 글은 서로 다른 카테고리로, 가능하면 하나는 다른 하나에 내부링크로 연결한다.
