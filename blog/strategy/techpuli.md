# 테크풀이 (Blogspot · 구글 애드센스) 운영 방향

> 네이버 3번 블로그(게임·AI/IT)와 주제가 겹치므로 **같은 주제를 그대로 옮기지 않는다** (중복 콘텐츠는 구글에서 불리). 공통 원칙은 `blog/strategy/campus.md` 2~3번.

## 독자와 검색 의도
- 구글 검색으로 들어오는 사람. "왜?", "어떻게?"를 묻는 설명형 검색이 많다.
- 이름 그대로 **풀이**: 뉴스 요약이 아니라 원리·이유·해결 방법을 차근차근 설명한다.

## 요청 단위
- 사용자가 "테크풀이 오늘의 키워드"를 요청하면 **글 2개** (따로 개수를 말하면 그 수).
- 1개는 시사성 있는 '왜 이런 일이?' 풀이, 1개는 오래 검색되는 '하는 법/해도 될까' 가이드를 권장.

## 쓰는 법 (구글 기준)
- 제목은 adsense-blog-writing 7번 구글 제목 규칙: `핵심 키워드 + 구체적인 문제 + 궁금증`, 키워드를 앞쪽에.
- meta.json 에 `description`(검색 설명, 120~150자) 필수 → 발행메모에 '검색 설명'으로 나간다. Blogger 글 설정의 '검색 설명'에 붙여넣기.
- tags 는 Blogger '라벨'로 쓴다 (5~10개).
- 결과 폴더: `blog/posts/techpuli/<날짜>/`, 압축파일 `테크풀이_블로그스팟_<날짜>.zip`

## 썸네일 테마
`it`(슬레이트), `ai`(틸), `game`(퍼플) — 네이버 3번 블로그와 같은 렌더러 사용.
