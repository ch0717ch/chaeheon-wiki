# 블로그 비교분석 · 운영 방향 (대학생활 정보노트 : 에디)

> 작성일 2026-10-02. 이 세션 컨테이너에서는 `blog.naver.com` 접속이 네트워크 정책으로 막혀 있어서
> 두 블로그 화면을 직접 열어보지 못했다. 아래 분석은 사용자가 말해준 현재 상태(짧고 정형화된 글,
> 눈에 안 띄는 썸네일, 일 방문자 약 30명)와 네이버 정보형 블로그 상위 노출 패턴을 바탕으로 했다.
> 레퍼런스 블로그(house_movie) 캡처 3~5장을 `blog/reference/`에 넣어주면 썸네일 템플릿을 거기에 맞춰 다시 조정한다.

## 1. 현재 블로그 진단 (eddiequate)

| 문제 | 왜 유입이 안 나오나 | 바꿀 방향 |
|---|---|---|
| 글이 짧고 정형화됨 | 네이버는 체류시간·스크롤 깊이를 품질 신호로 쓴다. 공고 요약만 있으면 원문(링커리어·학교 공지)으로 바로 이탈 | 공고 요약이 아니라 **판단을 돕는 글**: 비교표, 일정 패턴, 탈락 이유, FAQ |

| 마감 지난 공고 글 위주 | 공고글은 마감 후 검색이 0으로 떨어진다 | **에버그린 70 : 시즌 30** — 매년 반복 검색되는 주제(확인서 발급, 구간, 모집 시기)를 축으로 |
| 글끼리 연결 없음 | 한 명이 1페이지 보고 나감 | 글마다 후속글·관련글 링크 1~2개, 시리즈 이름 고정 |

## 2. 레퍼런스에서 가져올 것 (정보형 고유입 블로그 공통 패턴)

**이미지 스타일**
- 1:1 정사각형, 화면 꽉 차는 2~3줄 헤드라인 (Black Han Sans 계열 굵은 고딕)
- 핵심 숫자/단어 하나만 형광 박스로 강조 (`10개 → 5개`, `1365 vs VMS`)
- 상단 배지(무엇에 대한 글인지) + 하단 흰 카드에 "이 글에서 얻는 것" 3줄
- 블로그 이름을 하단에 고정 → 썸네일만 봐도 같은 시리즈로 인식

**글 스타일**
- 도입 2~3문장 안에 독자의 상황을 짚고 답의 방향을 먼저 말함
- 소제목은 질문형/결론형 ("그래서 금액은 줄어드나요?")
- 표 1~2개, 체크리스트, FAQ 2~3개, 마지막 "정리하면" 박스
- 기준일과 출처를 글 끝에 명시 → 신뢰 + 업데이트 글로 재활용

**검색 유도 스타일**
- 제목 앞쪽 15자 안에 메인 키워드
- 연도·숫자·질문 하나를 섞되 과장 표현은 쓰지 않음
- 태그 10개: 메인 2 + 롱테일 5 + 카테고리 3 (`#대학생활정보`는 매 글 고정)

## 3. 하지 않을 것 (이 블로그를 지키기 위한 선)

- 레퍼런스 블로그의 문장·이미지 그대로 복제 — 형식만 참고하고 내용은 직접 조사
- 확인 안 된 마감일·금액·후기 작성 (애드포스트 품질 평가에서 가장 위험)
- "광고 눌러주세요" 류 문구
- 같은 키워드로 표현만 바꾼 글 반복

## 4. 카테고리별 색 (썸네일 고정)

| 테마 키 | 색 | 쓰는 글 |
|---|---|---|
| `scholarship` | 네이비 + 노랑 | 장학금, 학자금, 등록금 |
| `volunteer` | 그린 + 라임 | 봉사활동, 해외봉사 |
| `activity` | 버건디 + 오렌지 | 대외활동, 서포터즈, 공모전, 서류·제도 |

## 5. 하루 3개 구성 원칙

1. **시즌/뉴스 1개** — 지금 발표되거나 곧 마감되는 것
2. **비교·판단 1개** — "A vs B", "언제 지원해야", "어떤 걸 골라야"
3. **방법·해결 1개** — 발급, 신청, 오류 해결처럼 매년 검색되는 에버그린

세 글은 서로 다른 카테고리로, 가능하면 하나는 다른 하나에 내부링크로 연결한다.
